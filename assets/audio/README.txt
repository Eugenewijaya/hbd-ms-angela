# PETUNJUK FILE AUDIO
Simpan file lagu ulang tahun Anda di folder ini dengan nama:
hbd.mp3

Path lengkap:
assets/audio/hbd.mp3

Catatan:
Jika file hbd.mp3 belum dimasukkan, website akan secara otomatis menggunakan
fitur cerdas Synthesizer Web Audio API (kotak musik instrumen Happy Birthday)
sebagai fallback, sehingga website tidak akan error dan tetap bersuara merdu!
